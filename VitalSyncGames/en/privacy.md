# VitalSync Games Privacy Policy

**Version:** 1.0  
**Effective date:** September 16, 2026  
**App:** VitalSync Games  
**Developer:** epicblue

## 1. Overview

VitalSync Games is a game application designed for playing Sudoku and other games that may be introduced in the future.

This Privacy Policy explains how VitalSync Games handles user information and application data created on the device.

## 2. Data collected and stored

In the current version, VitalSync Games does not require users to create an account and does not collect names, email addresses, phone numbers, addresses, contacts, location data, health information, or payment information for its core game functionality.

Application settings and game settings may be stored locally on the device. These may include:

- Application language
- Theme preference
- Game-specific settings

The application's local database is stored in encrypted form, and the database key is protected using the device's secure storage mechanism.

## 3. Game data

Future versions may introduce features such as game statistics, game history, or the ability to review completed games. If such a feature is introduced, the types of data stored and how they are used will be described in the relevant policy update.

## 4. Data sharing

In the current version, the local application and game settings described above remain on the device unless the user explicitly transfers data to an external service.

VitalSync Games does not sell user data or transfer personal data to third parties for advertising purposes in the current version.

## 5. Third-party services

Future versions may introduce advertising, cloud backup, or other third-party services. If such integrations change how user data is processed, this policy and the relevant store disclosures will be updated.

## 6. Data security

Appropriate technical measures are used to protect local application data. In the current version, the application's local database is encrypted.

However, no electronic storage or communication method can guarantee absolute security.

## 7. Data retention and deletion

The current version does not provide user accounts and therefore does not have an online account system requiring account deletion.

Local application data created on the device may be deleted when the application is uninstalled or when the operating system clears the application's data.

If a backup feature is introduced in the future, data exported by the user may also remain in the backup location selected by the user.

## 8. Children

VitalSync Games is not designed to knowingly collect personal information from children. If the target audience or data practices change in the future, the relevant policy and store disclosures will be updated accordingly.

## 9. Changes to this policy

This Privacy Policy may be updated when application features, data practices, or legal requirements change.

Each version is identified by the policy version and effective date shown at the beginning of this document.

## 10. Contact

For questions about privacy or data practices, users may use the epicblue developer contact channel. Current contact information will be provided on the application's Google Play store listing.
