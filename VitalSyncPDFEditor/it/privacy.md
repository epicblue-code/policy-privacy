# Informativa sulla privacy

## Informativa sulla privacy

VitalSync PDF Editor ("l'app", "noi", "nostro") rispetta la tua privacy. Questa Informativa sulla privacy spiega come l'app gestisce file, informazioni, abbonamenti e pubblicità.

## 1. File PDF ed elaborazione locale

VitalSync PDF Editor è progettato per elaborare i file PDF principalmente sul tuo dispositivo.

A seconda della funzione utilizzata, l'app può consentirti di:

- Creare file PDF
- Modificare file PDF
- Unire o dividere file PDF
- Convertire file PDF e altri documenti supportati
- Comprimere file PDF
- Estrarre o organizzare pagine PDF
- Visualizzare e salvare file PDF

I tuoi file vengono elaborati localmente sul tuo dispositivo. L'app non gestisce un servizio cloud controllato dallo sviluppatore per caricare o archiviare i tuoi file PDF.

## 2. Accesso ai file

L'app accede ai file solo quando necessario per fornire una funzione richiesta dall'utente.

Ad esempio, puoi selezionare un PDF, un'immagine o un altro file supportato per l'elaborazione. L'app può anche ricevere un file PDF quando scegli esplicitamente di aprirlo o condividerlo con VitalSync PDF Editor da un'altra applicazione.

L'app utilizza il file selezionato o condiviso esclusivamente per l'operazione richiesta.

## 3. Informazioni archiviate localmente

Alcune informazioni possono essere archiviate localmente sul tuo dispositivo per fornire le funzionalità dell'app e migliorare la tua esperienza. Possono includere:

- Informazioni sui file aperti di recente
- Preferenze dell'app e impostazioni di visualizzazione
- Firme create localmente
- Informazioni relative agli abbonamenti necessarie all'app
- Altre informazioni necessarie per le funzionalità locali dell'app

Queste informazioni vengono archiviate localmente mediante l'archiviazione o il database locale dell'app.

## 4. Firme

Se crei una firma con l'app, ad esempio una firma disegnata, basata su testo o su immagine, la firma può essere archiviata localmente sul tuo dispositivo per consentirti di gestirla e riutilizzarla.

L'app non carica le firme create localmente su un server controllato dallo sviluppatore.

## 5. Abbonamenti Premium

VitalSync PDF Editor può offrire abbonamenti Premium tramite Google Play.

Gli acquisti degli abbonamenti e l'elaborazione dei pagamenti sono gestiti da Google Play e dal sistema Google Play Billing.

L'app può archiviare localmente sul tuo dispositivo informazioni relative all'abbonamento per gestire l'accesso Premium e ripristinare gli acquisti. Google Play rimane la piattaforma pertinente per l'elaborazione delle transazioni di abbonamento.

Consulta le informative sulla privacy applicabili di Google per informazioni su come Google gestisce i dati relativi a pagamenti e acquisti.

## 6. Pubblicità

L'app include un'infrastruttura pubblicitaria e può mostrare annunci agli utenti che non dispongono di un'esperienza Premium senza pubblicità.

I servizi pubblicitari sono forniti tramite le tecnologie Google Mobile Ads.

Google e i partner pubblicitari possono trattare determinate informazioni secondo le proprie informative sulla privacy, le leggi applicabili e i requisiti della piattaforma. Le informazioni trattate possono dipendere da fattori quali dispositivo, regione, scelte relative al consenso e servizi pubblicitari utilizzati.

Per ulteriori informazioni, consulta le informazioni sulla privacy e le norme pubblicitarie di Google.

## 7. Connessione Internet

L'app può utilizzare una connessione Internet per funzioni quali:

- Servizi pubblicitari
- Google Play Billing e funzionalità relative agli abbonamenti
- Altri servizi forniti dalla piattaforma Android o Google Play

Le funzioni di modifica ed elaborazione dei PDF sono progettate per operare localmente quando supportato dalla relativa funzione.

## 8. Condivisione dei dati

Non vendiamo i tuoi file PDF né le firme create localmente.

L'app non fornisce un servizio cloud controllato dallo sviluppatore per archiviare i tuoi file PDF.

I servizi di terze parti, come Google Play Billing e Google Mobile Ads, possono trattare informazioni secondo i propri termini, informative sulla privacy e requisiti applicabili della piattaforma.

## 9. Sicurezza dei dati

Adottiamo misure ragionevoli nella progettazione dell'app per ridurre al minimo la gestione non necessaria dei file degli utenti. I file e le informazioni dell'app archiviate localmente restano inoltre soggetti alla sicurezza del dispositivo e del sistema operativo.

Nessun metodo di archiviazione o trasmissione elettronica può essere garantito come completamente sicuro.

## 10. Privacy dei minori

VitalSync PDF Editor non è specificamente rivolto ai minori.

Non gestiamo consapevolmente un servizio controllato dallo sviluppatore per raccogliere informazioni personali dai minori tramite l'app.

## 11. Modifiche a questa Informativa sulla privacy

Potremmo aggiornare questa Informativa sulla privacy quando l'app o le sue funzioni cambiano.

La data "Ultimo aggiornamento" nella parte superiore della pagina verrà modificata quando saranno apportate modifiche.

## 12. Contatti

Per domande su questa Informativa sulla privacy, puoi contattare lo sviluppatore tramite le informazioni di contatto presenti nella scheda ufficiale dell'app su Google Play o nelle pagine ufficiali del progetto.
